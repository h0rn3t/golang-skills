правки. Затем в отдельной копии плагина изменён только шаг 3

Четыре полноценные реализации `gateway`, по две на вариант. Обычный prompt

## Решение

Не переносить экспериментальный шаг в основной `go-code`. Полнота загрузки
owner-ов — отдельная метрика, она сама по себе не повышает эффективность.

Для продолжения на дереве второго раунда рекомендован один следующий
эксперимент: сократить ветки `go-http`, не используемые серверной задачей
(клиенты, middleware и полный lifecycle), оставив рядом с обработчиками
критические правила wire-формата и методного контракта. Отдельно проверить
клиентскую задачу, чтобы новая ссылка на вынесенные правила действительно
загружалась. Это гипотеза о сокращении объёма реально читаемого содержимого,
а не готовое изменение: ветки нельзя переносить без проверки достижимости.

Сравнивать с неизменённым вторым раундом при одинаковом effort. Изменение
effort требует собственной серии. Принимать сокращение по корректности и
цене; helpers и строки использовать как вспомогательные метрики. Не повышать
число обязательных загрузок ради самого счётчика.

Команды из `evals` на `74ca0fa` (в `CANDIDATE_ROOT` заранее распакован тот
же commit и применён только сохранённый patch):

```sh
go run ./cmd/abrun -corpus implement -tasks gateway -runner claude -model claude-sonnet-5 -arms baseline -n 2 -j 1 -seed 1 -timeout 5m -keep -out /tmp/routing-baseline.json
go run ./cmd/abrun -corpus implement -tasks gateway -runner claude -model claude-sonnet-5 -arms reference -reference-root "$CANDIDATE_ROOT" -n 2 -j 1 -seed 1 -timeout 5m -keep -out /tmp/routing-candidate.json
```

Второй отчёт называет эксперимент `reference` из-за интерфейса harness;
в сводке он обозначен `candidate`. Для сохранения raw stdout использовалась
временная обёртка `claude`, передающая все аргументы установленному CLI и
дублирующая stdout через `tee` в файл текущего scratch-каталога. Сам `abrun`
на этом commit полного журнала не сохраняет.

Стоимость четырёх новых сессий: **$0.9260318**. `quick_validate.py` для
экспериментального `go-code` прошёл; сравнение деревьев подтвердило изменение
только одного файла плагина. Структурная валидность не означает исполнения
инструкций — именно это проверял отдельный эксперимент.
