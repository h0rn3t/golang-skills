## Маршрутизація та вартість

`go-http` — 5/20, `go-error-handling` — 5/20, `go-linting` — 1/20.
У no-skill завантажень скілів не записано. По фікстурах:
`gateway` → `go-http` 5/5; `catalog` → `go-error-handling` 4/5;
`feed` → `go-data-structures` 0/5; `ledger` → `go-defensive` 0/5.

На `gateway` baseline додав функції в усіх п'яти сесіях: +1 у чотирьох,
+4 в одній; контроль — 0 у кожній. Це перевірено за Δfuncs, але причину
витягування хелперів без знімків коду встановити не можна.

За полем `cost_usd`: **$1.1985** без скілів, **$2.7825** зі скілами,
разом **$3.9810**. Середня вартість сесії — $0.0599 → $0.1391,
приблизно у 2.32 раза більше. Лічильників токенів у JSON немає;
це не вимірювання економії output tokens.

## Межі висновку

Це порівняння повного плагіна з його відсутністю, а не A/B скороченого
router або нового правила про хелпери. Хеш позначає конкретний baseline;
без його знімка не можна приписувати результат останнім локальним правкам.

Усі фікстури пройдено без скілів, тому цей прогін не демонструє зменшення
дефектів. На `gateway` без скілів Δрядків 64–68, зі скілами 66–87.
Для корпусу спостерігаємо більше типів і функцій та вищу вартість.
Для `gateway` відтворено точний двосторонній permutation test за модулем
різниці середніх: 6 із 252 розподілів, **p = 0.02381**. Це нескориговане
значення; якщо фікстуру обрано після огляду всіх чотирьох, поправка Бонферроні
дає **p = 0.09524**. Трактуємо як дослідницький сигнал, не доказ механізму.
Наданий звіт використовує population SD; таблиця вище — sample SD, тому
значення ± відрізняються без суперечності в даних.

Знімків згенерованого коду та повних транскриптів у вкладенні немає.
Фінальні повідомлення моделей не є незалежним підтвердженням заявлених
ними перевірок; тут враховано структуровані результати harness.
