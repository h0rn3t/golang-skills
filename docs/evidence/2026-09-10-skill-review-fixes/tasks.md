# Виправлення знахідок рев'ю Go-скілів

Дата: 2026-09-10. Обсяг: дев'ять знахідок рев'ю та пов'язані уточнення
прикладів. Коміт, публікація й інсталяція не виконувалися.

- [x] Пояснено межі `os.Root` для subprocess і передачу відкритого файла.
- [x] SQL-переказ використовує `UPDATE ... RETURNING`: відсутність будь-якого
  рахунку повертає помилку й спричиняє rollback.
- [x] Виправлено nil/empty-контракт `Clone` та прикладу збору ключів.
- [x] JSON-перевірка з безпеки маршрутизується до єдиного HTTP-прикладу.
- [x] `leaks` відокремлює успіх тестів від неперевірених витоків і повертає
  код 3 після успішних тестів, оскільки профіль не зібрано й не перевірено.
- [x] `errors.Join` перевіряється також за контрактом дерева помилок.
- [x] Для `clear`, `min` і `max` зазначено умови щодо NaN та знака нуля.
- [x] Розмежовано runtime FIPS-режим і build-time вибір модуля.
- [x] Бенчмарки скидають буфер; прибрано універсальні коефіцієнти прискорення.
- [x] Додано перевірку AES-ключа й автоматичний GCM nonce; уточнено числовий
  `LIMIT`, обмеження multipart і залежні очікування модельного eval.

## Перевірки

- `pass`: Go 1.27.1. Три нові регресійні тести спочатку відтворили дефекти:
  `[] → null`, panic на некоректному AES-ключі та хибний успіх `leaks`.
  Після виправлень вони проходять; приклади витягуються з Markdown.
- `pass`: розширені тести HTTP v1/v2 відхиляють зайві `]` та `}`; перевірка
  `database/sql` підтверджує rollback на EOF від драйвера для обох рахунків.
  Це перевірка Go-коду на межі драйвера, а не виконання PostgreSQL-запитів.
- `pass`: `go vet ./...` у `evals/`.
- `pass` після скорочення довідки: `go test -race -count=1 ./...` спочатку
  дав 333 успішних тести й одну помилку ліміту довжини `MODERNIZATION.md`.
  Після скорочення до 299 рядків повторено кореневий пакет:
  `go test -race -count=1 .` — 229 успішних тестів. Решта 105 тестів пройшла
  повний запуск; їхні пакети після нього не змінювалися.
- `pass`: `quick_validate.py` для п'яти змінених скілів і
  `agentskills-validate@1.0.1` для всіх 24 скілів.
- `pass`: чотири оновлені benchmark-функції з Markdown виконані через
  `go test -run=^$ -bench=. -benchmem -benchtime=50ms -count=1`.
  Це smoke-перевірка, не статистичний доказ прискорення.
- `fail`, без нових діагностик: `golangci-lint run ./...` у `evals/` має
  16 зауважень: 4 errcheck, 7 staticcheck, 5 unused. Порівняння з `HEAD`,
  розпакованим через `git archive` у тимчасову директорію, підтвердило
  побайтово однаковий вивід і код завершення 1.
- `unavailable`: PostgreSQL на локальному socket `/tmp/.s.PGSQL.5432`:
  `psql -X -w -d postgres` повідомив про відсутній socket.
- `skipped`: платні модельні A/B-прогони та перевірка сертифікованого
  FIPS-артефакту; інсталяція й release не входять до цього завдання.

- [x] Nil-контракт клонів додано в go-data-structures (власник колекцій) і

- [x] Таблиця депрекейтів у крипто-довіднику узгоджена з тілом розділу

- [x] Ламку контракту `leaks` перенесено в CHANGELOG із «Fixed» у «Changed»
